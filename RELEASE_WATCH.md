## Review a candidate

1. Confirm that the page names a new story rather than an edition, bundle, translation or reprint. Check the main catalogue and this queue for an existing work ID.
2. Record the publisher source, author, format, series, component stories, original publication where known, and date checked. Note conflicts instead of silently choosing one label.
3. Place the narrative using a cited range or explain why placement is uncertain. Do not turn a shop category into a precise in-universe date.
4. Write and review a spoiler-safe introduction. Record a dated review source before exposing it in default mode.
5. Add the stable work identity or collection relationship, regenerate derived data, and verify progress migration, search, direct links, collection contents and mobile layout.
6. Request a second editorial review for disputed format, canon, chronology or inclusion decisions. Update the public source note and build log after a substantive correction.

The publisher catalogue and availability can change. Recheck a listing when it is imported rather than treating this snapshot as a live store feed.
